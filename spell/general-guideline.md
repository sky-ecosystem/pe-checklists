# General Guidelines for Checklists

## How to complete the checklist

* **Do not remove** any checklist item. Only items with the `IF` prefix can be skipped. If such an item does not apply to the current spell, cross it out as `[ ] ~~checklist item~~`. If it has nested sub-items, cross those out as well.
* If an applicable checklist item cannot be completed or must be skipped, leave it unchecked and add a comment explaining why, marking it as either `blocking ❌` or `non-blocking ⚠️`.
* Only tick checklist items that are **fully completed**.
* For items marked as `LIST`, copy and fill in the relevant checklist for each applicable case.
